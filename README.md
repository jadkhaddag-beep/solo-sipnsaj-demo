# Solo Sip'n Saj — Demo Website

Demo website for **Solo Sip'n Saj** — fresh saj, specialty coffee, fresh juices & baguettes in Verdun, Beirut.

> "From Saj to Sip… it's a Solo Trip" — daily fresh dough · no oil · no sugar

## About

- **Location:** Verdun Main Street — facing Goodies Supermarket, Beirut, Lebanon
- **Ordering:** WhatsApp / Call +961 76 661 089 · +961 76 661 088 · Toters delivery
- **Instagram:** [@solo.sipnsaj](https://www.instagram.com/solo.sipnsaj)

## Tech

- Single-page static HTML/CSS/JS — no frameworks, no build step
- Photos curated from the restaurant's public Instagram feed (only clean food/kitchen shots — no promotional text cards, no holiday greeting posts)
- Hosted on GitHub Pages
