## What's inside

- **Hero** — brand tagline, bilingual EN/AR, quick Order-on-WhatsApp CTA
- **About** — the daily-fresh dough story (0% oil, 0% sugar, 100% taste)
- **Menu** — 4 tabs: Saj & Baguette / Coffee & Iced / Fresh Juices / Mojitos & Coolers
- **Gallery** — food & vibe shots with captions
- **Reviews** — placeholder testimonials (replace with real ones)
- **Visit** — address (Verdun Main St, opposite Goodies), phone, hours, Google Maps embed
- **WhatsApp ordering** — floating button + multiple CTAs to `wa.me/96176661089`
